Why you can check its work.

Every guarantee is enforced in code so an agent never asks you to trust a number or claim you cannot trace back to its source.

Code computes the numbers

A model never invents a statistic. The storyteller writer can only reference facts by name, and each fact is computed twice — once in pandas and once in separate SQL. If they disagree, the run fails.

pandas: 115286.00
duckdb: 115286.00
match: verified (Δ = 0)

You make the judgement calls

Is 05/02/2026 May or February? The file cannot say. An agent stops and asks you; pass assume_defaults=true and every guess stays in the report, flagged in red as unconfirmed.

row 4: 05/02/2026 → 2026-05-02
assumed, not confirmed: month first

Strange repositories stay inert

Point margin at any GitHub URL or local folder. Files are read and never executed, and git is locked down with read-only configuration so a hostile repository cannot trigger hooks or helpers.

core.hooksPath=/dev/null
core.fsmonitor=false

Data Storyteller

PyPI · Experimental · No model required

Cleans messy CSVs and spreadsheets, accounts for every changed cell, computes every fact twice in pandas and DuckDB SQL, writes the story with charts, and exports clean CSVs or Power BI .pbip projects.

pip install margin-cli margin-data-storyteller

AI Code Detector

PyPI · Experimental · GitHub URL or path

Estimates how likely a codebase was written with AI assistance as a plausible range with a confidence level, backed by verbatim quoted lines and commit-level evidence for and against.

pip install margin-cli margin-ai-code-detector

Commit Graph

PyPI · Experimental · SVG, Markdown, JSON

Draws a repository's history as a readable ink-lane SVG tree and groups its evolution into narrative chapters, margin notes beside commits, and the files that keep changing.

pip install margin-cli margin-commit-graph
Documentation ↗

Secret Leaks

Experimental · No model required

Scans workspace files and full git history for hardcoded secrets, API keys, private keys, and credentials — reporting exact locations with strictly redacted previews.

margin run secret-leaks .
